# Shop Engine

Модуль содержит ядро для e-commerce приложения.

## Функционал
- Реализованы классы `Product` (товар) и `Category` (категория).
- Атрибуты классов `category_count` и `product_count` автоматически считают общее количество категорий и товаров при инициализации объектов.
- Реализована функция `load_categories_from_json` для загрузки данных из JSON-файла.
- Написаны тесты (`pytest`), покрытие кода >75%.
