# Shop Engine

Ядро для e-commerce приложения на Python. Проект демонстрирует принципы объектно-ориентированного программирования (ООП), включая инкапсуляцию, работу со свойствами (геттеры и сеттеры) и класс-методы.

## 🚀 Функционал

- **Класс `Product`**: Описывает товар.
  - Реализована инкапсуляция цены (приватный атрибут `__price`).
  - Настроены геттер и сеттер для цены с проверкой на отрицательные значения.
  - Добавлена логика подтверждения при понижении цены.
  - Реализован класс-метод `new_product()` для создания товара из словаря с поддержкой объединения дубликатов.
- **Класс `Category`**: Описывает категорию товаров.
  - Инкапсулирован список товаров (приватный атрибут `__products`).
  - Реализован метод `add_product()` для безопасного добавления товара.
  - Настроен геттер `products`, возвращающий отформатированную строку со списком всех товаров.
  - Автоматический подсчет общего количества категорий (`category_count`) и товаров (`product_count`).
- **Загрузка данных**: Функция `load_categories_from_json()` для инициализации объектов из JSON-файла (`products.json`).
